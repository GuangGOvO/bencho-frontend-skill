# 动效、输入和可访问性

## 动效实现

轻量反馈用 CSS 的 transform/opacity。只对需要动画的属性声明 transition；避免 `transition: all`。位置、尺寸或内容同变时确定一个共同状态源，避免两个独立动画互相追赶。

手势实现用 Pointer Events，按下捕获指针，处理 `pointerup`、`pointercancel`、`lostpointercapture` 和卸载。坐标相对控件矩形计算并夹到合法范围。水平手势保留纵向滚动，视需要用 `touch-action: pan-y`。能用原生 range 时优先复用它的输入能力。

高频输入用 motion value、ref 或 rAF，减少整棵 React 树每帧 render。rAF、事件监听、ResizeObserver、音频和计时器在卸载清理。React SSR 环境不要在模块顶层读取 window/document；媒体查询和尺寸观察放到客户端 effect 或 CSS。

弹簧适合释放、吸附和形态恢复，固定时长适合进入/退出。不要同时把手势目标和弹簧目标当作当前位置。速度阈值、确认阈值与行程由实际控件尺寸和业务要求决定。

## 输入等价与语义

- Hover 有 focus 等价，触屏能点击显示/展开；装饰 hover 允许省略。
- 拖动有键盘路径，排序有显式移动控件；触屏不能被强制当作鼠标。
- Slider 优先 `<input type="range">`；自定义实现必须维护完整数值语义和方向键/Home/End。
- 实际开关用 checkbox/switch，选择按钮使用 `aria-pressed`；菜单和列表不混淆各自键盘模型。
- 对话框或弹出菜单处理进入/退出焦点。内联确认取消时焦点回原按钮，失败时保留可重试路径。
- 图像比较为图片提供有意义的替代说明，并为百分比提供可读值。
- 异步结果通过稳定的 `role="status"` 或适当 live region 宣告，不对每帧数值播报。
- 标签可点击并保持可见；原生表单提交、浏览器 autofill、验证码粘贴不可被装饰层阻断。

## 减少动效与视觉可达性

用 `@media (prefers-reduced-motion: reduce)` 关闭装饰移动、循环、粒子和夸张弹簧，保留可理解的瞬时状态变化。JS 动画库同样读取对应偏好；CSS 规则不能关闭所有 Canvas/JS 动画。

保证焦点环不被 overflow 或滤镜截断，状态不只靠颜色，文字和控件对比足够。保持页面缩放；小视觉对象通过 padding 或伪元素扩大触控范围，尽量达到 44px 级别，不能导致邻近操作误触。

## 有意义的检查

| 场景 | 应看到的结果 |
| --- | --- |
| Tab、Enter/Space、Escape | 进入控件、执行主操作、退出临时状态，焦点位置清楚 |
| 触屏/窄屏 | 主要任务不依赖 hover，横向手势不吞纵向滚动，布局不溢出 |
| 减少动效 | 动作仍可完成，循环与大幅位移停止 |
| 快速连续操作 | 单次请求语义明确，不重复提交或出现陈旧结果覆盖 |
| 失败/取消/卸载 | 正确回退，无悬挂监听、定时器或无限加载 |
| 边界值/空内容 | 夹取合法范围，标签、图片和空态仍可辨 |

按改动规模选择浏览器和自动化验证，不为纯样式常量写镜像测试。对真实手势状态机、异步竞争和更新脚本的解析失效，使用可观察的行为验证。
